# Security Documentation

This site contains sanitized, authorized cybersecurity work, technical walkthroughs, research notes and project documentation.

## Documentation standard

Every entry should make the work reproducible, explain the security impact, cite its sources and state its limitations.

## Safety boundary

Only document systems you own or are explicitly authorized to test. Never publish credentials, tokens, private client information, sensitive screenshots, internal hostnames or unredacted logs.
